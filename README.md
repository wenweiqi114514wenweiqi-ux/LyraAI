# Lyra-1 · 天琴

一个**从零训练的中文迷你对话语言模型**——完全用 Python + PyTorch 在纯 CPU 上训练，适合学习、演示与开源示范。

Lyra 取意自天琴座（Lyra），中文名「天琴」，就像夜空中一颗温柔发光的星星。

---

## 它能做什么

| 能力 | 方式 | 说明 |
|---|---|---|
| 日常对话 | 模型自己生成 | 「你好」「什么是人」「什么是人工智能」等固定问答可稳定复现 |
| 数学计算 | 工具辅助 | 四则运算、比大小，Python 精确计算，杜绝幻觉 |
| 中英互译 | 工具辅助 | 常用词表双向互译，未收录词诚实兜底 |
| 温柔诗意风格 | 底层设定 | 回答温柔、稳定、有温度 |

> 数学与翻译由「工具调用」完成——这是真实大模型（GPT/Claude 等）的标准做法：模型负责理解与表达，工具负责精确结果。

---

## 模型架构

- **类型**：GPT 风格 decoder-only Transformer（因果自注意力）
- **参数量**：约 250 万
- **配置**：`vocab_size=4096` · `n_embd=192` · `n_head=8` · `n_layer=4` · `block_size=1024`（约 1K 上下文窗口）
- **分词**：jieba 词级 tokenizer（词表 3735）
- **共享权重**：词嵌入与输出层共享（减少参数）

## 训练数据

- **对话语料**（`CONVERSATIONS`）：日常沟通、常识问答、情绪回应、AI 原理等 169 段
- **正式知识材料**（`KNOWLEDGE`）：地球、太阳系、天琴座、AI 历史、国际与时事等纯文本预训练语料
- **核心问答强化**（`CORE_QA`）：12 条高频日常问答做固定模板、重复 20 次；「你好」单独重复 40 次——让小模型稳定复现门面问答

## 训练方法

- **目标**：自回归预测下一个词（监督微调 SFT），损失只在「助手回复」部分计算（用户话术被 mask）
- **策略**：分段多次少量训练，每段 1000 步
- **权重管理**：
  - `lyra_best.pt` —— 验证损失最低的最佳权重（坏的权重自动被剔除）
  - `lyra_last.pt` —— 最近一次训练权重
  - 数据指纹校验：换数据不允许续训，防止污染
- **当前状态**：7000 步，验证损失 **2.08**

## 快速开始

```bash
# 1. 训练（可选，已有权重可直接推理）
python3 train.py --steps 1000            # 从零训练一段

# 2. 推理对话
python3 chat.py "你好"
python3 chat.py "你是谁"
python3 chat.py "3加4等于多少"            # 工具精确计算
python3 chat.py "苹果用英语怎么说"         # 工具互译
```

## 文件说明

| 文件 | 作用 |
|---|---|
| `lyra_model.py` | Lyra 模型定义 |
| `train_data.py` | 训练数据 + 词级 tokenizer |
| `train.py` | 分段训练脚本（权重管理/指纹/续训） |
| `chat.py` | 推理入口（含工具辅助层） |
| `lyra_best.pt` / `lyra_last.pt` | 训练好的权重 |

## 环境要求

- Python 3.10+
- `torch`（CPU 版即可，本项目无需 GPU）
- `jieba`（中文分词）

```bash
pip install torch jieba
```
